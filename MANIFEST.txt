What is included
----------------------------------------------------------------
  M1  foundation: config, PostgreSQL schema, Redis, auth, health, Persian RTL shell
  M2  providers & credentials: CRUD, encrypted secrets, verification, connectivity test
  M3  models: discovery, pricing, capabilities, playground
  M4  API keys and the OpenAI-compatible public gateway (/v1)
  M5  routing engine, dry-run simulator, scheduled upstream health checks
  M6  usage analytics, request logs, CSV/JSON export, daily rollups
  M7  hardening: code splitting, focus contract, performance indexes, seeds, docs

Deliberately not included
----------------------------------------------------------------
  .env (secrets)          — copy .env.example and fill in the two keys
  node_modules/, dist/    — run `npm install` / `npm run build`
  local database data     — create it with `alembic upgrade head`

Run it
----------------------------------------------------------------
  backend :  cd backend  && pip install -e . && alembic upgrade head
             uvicorn app.main:app --reload
  frontend:  cd frontend && npm install && npm run dev   (proxies /api to :8000)
  demo data: cd backend  && python -m app.seeds           (opt-in, rows marked (demo))
  tests   :  cd backend  && pytest       |  cd frontend && npm test
